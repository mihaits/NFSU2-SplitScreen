# tools

Test and reverse-engineering helpers. Check this repo out anywhere inside the game folder (`paths.py` finds it: the
nearest parent holding speed2.exe); the scripts read `<game>/speed2.exe` and `<game>/scripts/NFSU2SplitScreen.log`. Live tools need the game running, and the mailbox
tools need `Debug = 1` in the ini. See [docs/tooling.md](../docs/tooling.md).
