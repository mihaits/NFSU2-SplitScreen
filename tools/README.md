# tools

Test and reverse-engineering helpers. Check this repo out inside the game folder (`<game>/<repo>/tools`); the scripts
read `<game>/speed2.exe` and `<game>/scripts/NFSU2SplitScreen.log`. Live tools need the game running, and the mailbox
tools need `Debug = 1` in the ini. See [docs/TECHNICAL.md, section 15](../docs/TECHNICAL.md#15-tooling-and-workflow).
